# 映流 v0.3.0 Media Pro 设计
用户授权：按附件直接实现全部 P0、P1；P2 媒体库/AI/素材分析与 AV1 编码预留。来源附在同目录 media-pro-taskbook.md。

## 结构
复用 v0.2 ffmpeg 的探测、串行任务、Windows Job、进度、原子状态和不覆盖发布。新增 media 模块负责编辑辅助、压缩、预设、自动处理、字幕、批处理、抽帧、联系表、封面与元数据；service.rs 仅添加下载完成回调。
结构化 MediaRequest 扩展操作和专用参数，旧记录默认值保持兼容。批次由多个 MediaTask 组成，逐文件反馈；最大 500 文件，递归遍历不跟随链接。

## 裁剪
现有媒体页面增加预览、播放工具栏、双端点时间轴、缩略图及设置。浏览器不支持源编码时由 Rust 生成低分辨率 H.264/AAC 预览代理；输出仍用原始视频。Tauri asset scope 仅逐文件授权，不开放磁盘目录。缩略图按 2/5/30 秒规则，分批 60 张加载。输入和滑块共用秒数，毫秒显示；未知 FPS 不猜测逐帧。J 用倒向寻帧模拟预览；输入框/下拉框不截获快捷键。

## 处理
压缩复用编码路径，新增 1440p。预设可保存/应用/删除，四个内置预设；AI 素材另生成缩略图。自动处理默认关闭，只对启用后完成的新下载运行；关联下载 ID 去重、独立媒体失败/重试，保留下载源。自动字幕是封装已下载或内嵌文本字幕，缺少时显示错误，不进行语音识别。
GPU -encoders 仅是声明，需实际启动探测；所选 GPU 不可用或任务启动失败后回退 CPU，清理该尝试临时结果。硬件质量参数与 CPU CRF 含义不同，界面说明。
字幕支持 SRT/ASS/VTT 转换、软字幕封装、字体/大小/位置/颜色烧录。封面提取/设置、元数据写入均输出新文件。
抽帧限制最多 10000 张，时间间隔/数量/FPS 三种模式；整目录验证后不覆盖发布。联系表通过 FFmpeg tile/drawtext 输出单图，包含时间码、文件名和尺寸。

## 界面
保留石墨灰、青蓝、Windows 中文系统字体和 Lucide 图标。编辑预览为视觉中心，下方时间轴，上方少量操作导航；高级参数逐步展开。所有滑块有标签/键盘替代，减少动画、880px 最小窗口与高 DPI 检查。ui-ux-pro-max 搜索偏营销模板，采用其专业工具风格、可见焦点和对比度原则，布局按现有桌面产品设计。
