# 映流 v0.4.2 · 内置原生播放设计

## 已确认的需求

用户反馈 v0.4.1 等待完整兼容视频转换太慢，要求点击课程就能看。已明确选择“仍在映流内播放”，并确认“内置 mpv 直接读取原文件；保留进度、倍速、字幕和笔记；整段转码仅为手动兜底；安装包随附播放内核”。这是现有学习播放器内核的架构调整。

成功标准：正常本地素材秒级开始出画；不以整段转码完成作为开始播放条件；拖动到尚未观看的位置也可直接解码；原片、旧课程、进度和笔记保留。对损坏、加密或硬件无法实时解码的文件明确显示错误或性能限制，不承诺所有文件绝对零等待。

## 故障证据与方案比较

公开 WMV3/WMAPro 样本长度156.958秒。原版实际首帧解码433ms；调用真实学习播放器准备接口5秒后仍未就绪，CPU兼容转码62%。旧逻辑等待 MediaTaskStatus::Completed 才发布完整缓存，界面等待整片处理。硬件编码不可用使等待更明显，但改变编码速度仍保留整片等待。

1. **采用：内置原生 mpv。** 解复用、解码和显示按播放需要执行，不先转换整片；也不依赖浏览器的WMV/HEVC支持。
2. **不采用：只调快转码。** 仍然需要等完整文件，不满足本次诉求。
3. **不采用：自行实现边转边播。** 需要分片服务、浏览器MSE、跳转重启和缓冲管理，仍需实时编码；成熟播放内核已覆盖需求。

## 播放路径与界面

默认学习播放改用捆绑的 mpv 原生内核。画面嵌入映流现有视频区域，保留课程列表、控制条、笔记、时间点跳转、字幕选择、全屏与快捷键。用户不安装外部播放器，也不打开独立播放窗口。

原“自动选择”“优先原始视频”均直接使用原文件；“始终生成兼容视频”以及“重新生成兼容视频”保留现有完整缓存和WebView播放路径，作为明确的手动兼容方式。正常原生播放不创建兼容视频任务。已有缓存可保留供手动兼容使用，不自动清空。

前端复用现有控制与进度逻辑，以小型播放句柄连接WebView或原生后端；不重复制作一套学习页。原生事件包含session/itemId，迟到事件不得切换当前课。准备状态只覆盖打开文件、解码首帧和发生的错误，不再展示整片编码进度。

字幕由原生内核直接处理嵌入字幕及验证过的本地字幕，避免打开前先扫描整片提取字幕；原WebView兼容路径继续使用现有VTT缓存。笔记保持原课程ID与时间轴。

## Rust与Windows边界

新增学习播放原生会话模块，复用现有Windows Job Object、参数数组进程启动、文件校验和资源定位。一个学习播放器对应一个活动原生会话；默认播放不排入媒体转换队列，不增加另一套转码器。

mpv以受控独立进程运行，通过Windows子窗口嵌入视频区域、命名管道JSON IPC获取状态和执行有限的播放命令。父窗口和几何位置由应用验证；前端不能提交任意HWND、任意内核参数或任意IPC命令。

仅支持暂停/播放、绝对跳转、倍速、音量/静音、字幕和状态读取等固定操作；对session、数值范围和本地文件做校验。禁用用户配置、自动脚本、外部引用和网络输入；只打开已验证普通本地媒体/字幕。退出、切课、取消与异常时终止所属进程树、关闭IPC、销毁所属子窗口。

原生容器随窗口缩放、滚动、DPI及全屏更新；隐藏页面或弹窗时正确隐藏原生画面，防止挡住界面。用户关闭主窗口进入托盘时暂停并保存当前学习进度，保留原有后台下载行为。

原生实际位置与倍速在暂停、隐藏、切课和退出前写入既有进度接口；正常播放继续定期保存。保存与关闭按会话排序，避免旧会话的迟到结果覆盖新课进度。课程缺失、重新定位、被移除时沿用已有保护。

## 组件、版本和数据

版本0.4.2，不修改学习库表结构，不引入新的业务设置或重复的GPU开关。原生播放优先安全硬件解码，设备不支持时由mpv回退软件解码；不把硬件“编码器不可用”当作无法直接播放。

准备脚本增加固定mpv Windows x64发行包；使用项目安装页列出的构建来源或一手CI构建，校验发行资产SHA256、二进制摘要及启动版本；随包提供实际版本、来源、构建信息与许可证。启动时不联网下载组件。保留原yt-dlp/FFmpeg/ffprobe/Deno及其校验。

继续使用现有独立工作树，新分支 `codex/native-learning-playback-v0.4.2`，基于v0.4.1最终提交。交付新的中文NSIS安装包、源码ZIP、校验清单和新Draft PR；不覆盖旧安装包/PR历史，不合并或发布Release。

## 验证

先保留旧版5秒未就绪的失败基线，再测真实原生首帧时间。相同157秒WMV在本机正常负载目标为3秒内出画，硬验收为5秒内就绪且不启动整片兼容转换；记录实际测量值，不将本机结果泛化为所有设备。

真实12种容器/编码，重点WMV3/VC-1、MKV、AVI、HEVC：直接首帧、播放、暂停、跨段Seek、倍速、字幕、笔记跳转、上下课、退出恢复、切课/取消竞态。确认原文件SHA256不变，媒体转换队列不被默认播放占用。

窗口缩放、880宽、高DPI与全屏、弹窗遮挡、托盘隐藏、键盘操作；硬件不可用软件解码；损坏媒体及丢失内核提示；手动兼容转码路径与旧下载/Media Pro回归。运行现有Rust/Node/前端构建与NSIS构建，并对新增原生会话边界保留可复现检查。
