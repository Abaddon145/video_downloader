# Media Pro Implementation Plan
> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax.
**Goal:** 实现 v0.3 的全部 P0/P1，并交付可测试源码和安装包。
**Architecture:** 复用 FFmpeg CLI/MediaService 安全边界；专用 media 模块和 React 小组件。
**Tech Stack:** Tauri 2、Rust、React、TypeScript，已有依赖。
**Spec:** docs/superpowers/specs/2026-10-11-media-pro-design.md 与 media-pro-taskbook.md
## Global Constraints
不改变下载、Cookie、代理、播放列表、断点续传、托盘和历史；所有 FFmpeg 经 Rust；不复制第三方源码；禁止覆盖；保持 UI；版本 0.3.0。
## Review Focus
1. 中文及含引号的辅助字幕/封面路径必须保持字面值，不能注入滤镜。
2. 长视频预览取消与页面切换必须终止辅助进程、忽略迟到结果。
3. GPU 声明但缺驱动必须回退 CPU，不将任务假报成功。
4. 批处理链接/损坏文件、同名输出不能损坏源文件或已有文件。
5. 自动处理完成/重启竞态必须去重，不能重下载或处理旧历史。
