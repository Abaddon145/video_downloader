# 媒体工具（v0.2.0）

映流使用捆绑的 FFmpeg 和 ffprobe 处理本地文件，不需要另装 FFmpeg。媒体处理与下载任务分别排队；媒体队列同时处理 1 个任务。

## 使用

1. 左侧打开「媒体工具」，选择或拖入一个本地媒体文件。
2. 查看摘要；「完整媒体信息」中可以展开全部视频、音频、字幕轨道与元数据。未知字段显示「未知」。
3. 选择一种操作，设置格式和保存目录，再开始处理。
4. 完成后打开文件或目录。失败时可展开技术详情，更换选项后新建任务，或「重新开始」原任务。

默认保存在源文件所在目录。原文件保留；同名输出自动加 (1)、(2) 等编号。处理时在保存目录的 `.video-downloader/media-temp/<任务ID>` 写入临时文件，成功才发布结果，正常取消后清理该任务临时文件。

## 操作与边界

| 操作 | 选项与说明 |
| --- | --- |
| 格式转换 | MP4、MKV、MOV；默认 H.264/AAC；质量分最高、平衡和更小体积。高级选项含 H.265、Copy、最高 720/1080/2160p、24/25/30/60 FPS、CRF 与音频编码/码率。分辨率设置只降低较大画面，不放大源视频 |
| 极速无损转换 | MP4、MKV、MOV、WebM；保留全部受支持的视频、音频和字幕轨道。任何轨道不兼容就拒绝处理，建议 MKV 或兼容转换 |
| 视频裁剪 | 单个时间段；输入 MM:SS.mmm 或 HH:MM:SS.mmm，开始 < 结束 ≤ 时长。极速模式复制全部兼容轨道，切点可能受关键帧影响；精确模式重新编码 |
| 提取音频 | 默认 MP3 320 kbps，另支持 M4A、AAC、WAV、FLAC、Opus；原始编码复制须与目标容器兼容。更高码率不会提升原始音质 |
| 视频截图 | 指定毫秒时间，输出 PNG、JPG 或 WebP；一次截取一帧 |

格式转换、精确裁剪、音频提取和截图使用第一条对应轨道，界面有提示；多轨选择留待后续。无损转换/极速裁剪不会静默丢弃不兼容的轨道。

WebM 首版只允许兼容源流的无损封装/极速裁剪，例如 VP8/VP9/AV1 搭配 Opus/Vorbis；不提供 VP9 转码。视频 Copy 禁用分辨率、帧率与 CRF。当前支持范围较保守，Opus 视频音轨只允许 MKV；不承诺覆盖 FFmpeg 的全部格式组合。

## 任务与退出

任务状态为等待、分析、处理、中断、完成、失败、取消。进度来自 FFmpeg 结构化输出，包括已处理时间、速度与预计剩余时间；未知值不会伪造。

处理支持取消，不提供暂停续传。失败、取消、中断任务可以重新开始，完整重跑。关闭窗口隐藏到托盘继续工作；主动退出终止媒体进程树并保存记录。下次启动后未完成媒体任务显示中断，需手动重新开始。

媒体任务记录独立保存在应用数据目录的 `media-state.json`，原子写入并保留 `media-state.bak`。无效记录及备份会保留，媒体工具提示错误，下载功能仍可使用。异常断电/强制结束可能留下该任务临时文件；默认不清理不属于当前任务的文件。

## 组件与许可

「设置 → 第三方组件版本与许可」可查看版本与来源。安装目录包含 `components.json`、`tools/binaries.json`、`THIRD-PARTY-NOTICES.txt` 和 `licenses`。

捆绑 FFmpeg/ffprobe 为 `N-127236-g17ec998942-20261007`，启用 GPL 和 version3，遵循 GPL-3.0-or-later。[构建来源](https://github.com/yt-dlp/FFmpeg-Builds)，[FFmpeg 许可与源码说明](https://ffmpeg.org/legal.html)。组件校验失败时会阻止媒体处理并提示重新安装。

暂不提供 GPU 转码、复杂滤镜、多段裁剪、批量文件夹、字幕编辑、AV1 高级设置或任意自定义命令。
