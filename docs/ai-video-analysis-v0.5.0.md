# 映流 v0.5.0 AI视频学习分析

## 从对应课程开始

打开学习库中的系列，在课程旁点击“AI分析”。视频与学习面板并排展示，宽窗口约65/35，窄窗口改为上下布局。面板固定为总结、字幕、问答、笔记四页，不需要切换到单独AI工作空间。媒体工具的AI按钮和下载完成任务上的AI按钮同样进入对应课程；重复导入已有媒体会复用课程记录。

开始前可选择快速、标准、深度模式，确认发送字幕或精选画面的范围。两种上传都关闭时只允许本地转录，不提交AI理解。现有字幕优先，缺少有效文本字幕且有音轨时才调用本地Whisper；没有音轨的媒体可以仅分析画面，纯音频可以本地识别并做文字理解。

## 本地与网络

原视频和完整WAV不会交给DeepSeek。FFmpeg和Whisper运行在本地，DeepSeek只收到允许的文字与经缩放的精选JPEG。模型默认DeepSeek Flash，配置与API调用只在Rust安全层；API密钥在Windows安全窗口录入，DPAPI加密保存，React只能看到是否已设置。API固定官方HTTPS地址，不提供自定义Endpoint。

Whisper模型首次使用时下载或导入，不塞进NSIS安装包。Base与Small的固定版本、URL、字节数、SHA256及许可证见随包组件清单；下载先写临时文件，校验通过后才启用。已有可用字幕时不要求安装Whisper模型。

## 播放与检索

总结包含概要、章节、知识点、教程步骤、术语、标签与待办。点击章节或问答引用的时间即可使用原播放器跳转。“解释这一段”只查询当前位置附近字幕与必要画面，不重新分析整部视频。问答先在本地检索相关片段，信息不足允许明确回答没有找到足够内容。

字幕每页50段，跟随播放自动定位、高亮；手动翻页后暂停跟随，可重新勾选。支持同名SRT/VTT/ASS/SSA和可转换的内嵌文本字幕，位图字幕不做OCR。多语言当前按稳定文件名顺序选择，AI字幕栏暂不联动播放器临时加载的非同名字幕。

## 任务、费用与恢复

AI队列独立于下载队列，同一时间分析一部媒体，分段请求默认1路、最多2路。任务可取消和重试，已完成的转录、画面和分段结果可复用；软件重启后的中断任务需手动恢复。“重新生成总结”与“重新完整分析”分开，前者复用本地材料。课程分析历史只显示该课程当前源文件的记录。

下载完成自动分析默认关闭，只有在设置中明确开启后才处理新完成媒体，不会启动时重放历史。AI设置显示原始输入、输出及缓存Token，费用为参考，实际以DeepSeek账单为准。没有配置真实密钥的本机验收采用明确标注的模拟HTTP；不能据此声称真实API已验收。
