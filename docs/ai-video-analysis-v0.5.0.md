# 映流 v0.5.0：AI视频学习

v0.5.0 候选版本。真实 DeepSeek 短片验收已通过；完整范围与待验收项见[交付记录](ai-video-analysis-delivery.md)。模拟接口检查和真实服务检查分别记录。

## 从课程开始

在学习库打开系列，选择课程旁的 **AI分析**。AI功能位于课程学习面板的总结、字幕、问答和笔记页中，没有独立 AI 导航页。媒体工具和下载任务中的 AI 入口也会把媒体导入学习库并打开对应课程；已有媒体会复用课程记录。

分析时可选快速、标准或深度模式，并确认是否允许发送字幕文字和精选画面。开始分析需要至少允许其中一类内容发送。关闭两项后仍可在本机转录，但不会向 DeepSeek 提交内容来生成 AI 理解结果。已有可用字幕优先；没有有效字幕且媒体含音轨时，映流使用本地 Whisper 转录。无音轨视频可只分析画面；纯音频可本地转录并进行文字分析。

设置中的模型选择随分析内容受限：DeepSeek Flash 支持文字和画面；DeepSeek Pro 仅用于文字分析，开启画面上传时不可选。语音识别模型在本机选择 Base、Small 或自行导入的模型；Base 较快，Small 通常更精细，处理速度也取决于电脑性能。Whisper 模型首次使用时下载或导入，不包含在安装包内；下载文件先校验 SHA256 后才启用。已有可用字幕时无需安装 Whisper 模型。

## 总结、字幕与问答

总结可包含概要、章节、知识点、教程步骤、术语、标签和待办。点击章节或问答引用时间会让原播放器跳转。“解释这一段”只使用当前位置附近的字幕和必要画面，不重新分析整段视频。问答先在本机检索课程材料；内容不足时会说明没有找到足够依据。

字幕按每页 50 段显示并可跟随播放定位。手动翻页会暂停跟随，可重新开启。支持同名 SRT、VTT、ASS、SSA 及可转换的内嵌文本字幕，不对位图字幕做 OCR。多语言字幕按稳定的文件名顺序选择；播放器临时加载的非同名字幕暂不联动到 AI 字幕页。

## 笔记与知识库

分析后可把总结生成到所选知识库中的 Markdown 笔记，也可从播放位置创建带截图的时间点笔记。自动生成知识笔记默认开启，但需要先选定知识库；关闭后可在课程笔记页手动生成。生成知识笔记仅把已有结果写入本地 Markdown，不调用 AI。重新生成总结会调用 DeepSeek，但复用已有转录与画面；这两种操作都不会上传原视频。阅读[知识库说明](knowledge-vault-v0.5.0.md)了解编辑与删除规则。

## 隐私、用量与任务

原视频和完整 WAV 留在本机。按设置允许后，DeepSeek 可接收字幕文字及缩放后的精选 JPEG；不会收到视频文件或完整 WAV。密钥通过 Windows 原生安全输入窗口录入，并由 Rust 后端使用 Windows DPAPI 加密保存。设置页不回显密钥，只显示是否已设置。测试连接只读取模型列表，不发送课程内容。更多细节见[DeepSeek隐私说明](deepseek-privacy-v0.5.0.md)。

自动分析新下载默认关闭；打开后只对之后完成的下载生效，不会启动时追跑历史任务。AI任务与下载队列分开，同一时间处理一部媒体；分段请求默认并行 1 路、最多 2 路。任务支持取消和重试，已完成的转录、画面和分段材料可复用；应用重启后中断任务需手动恢复。AI设置显示输入、输出和缓存的原始 Token 数；费用估算仅供参考，实际账单以 DeepSeek 为准。

## 当前边界

本机真实短片已验证文字和 JPEG 分析、章节、问答引用与用量，不等同于全部语言、长课质量或所有 Windows 设备均已验证。范围与安装包见[交付记录](ai-video-analysis-delivery.md)。

本次短语音验收中，极短韩语和拼接中英样本存在识别错误或漏句，详见交付记录。已有可信字幕优先于语音识别；自动转录结果应人工核对。
