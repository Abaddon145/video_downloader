# 映流 v0.5.1：Markdown知识工作台

笔记始终是 Vault 中的普通 Markdown 文件；SQLite仅保存索引、关联、收藏、模板标记和历史快照。映流不打包 Obsidian、不修改 `.obsidian`，无需安装 Obsidian 也可完整使用知识库。

## 标签与保存

点击文件树可打开多篇笔记，每个文档独立自动保存。保存期间可以继续输入；回执只确认其请求快照，不会替换后来输入。写入失败保留草稿，外部修改会暂停自动保存并要求选择。Ctrl+S 可以手动重试。离开页面、关闭未保存标签、切换 Vault 或主动从托盘退出时，会保护所有打开的草稿。

当前最多打开20篇笔记。其他 Vault 的标签仅在本地保留会话，不允许继续写入；切换前处理未保存内容。文件移动前排空相关保存，成功后更新会话路径；失败保留原目标。强制终止进程和断电不能保证未落盘输入恢复。

## 富文本与源码

编辑、富文本、预览和分屏共用同一 Markdown 保存链。富文本采用固定版本 Tiptap，支持可安全写回的段落、标题、粗体和斜体。未修改内容保留原文。YAML、Wiki Links、附件、任务、代码块、Obsidian特殊语法、BOM/CRLF及不能证明无损的排版，明确回退到 CodeMirror 源码编辑；不会默默清理特殊语法。

不能安全序列化的富文本交易会被拒绝并提示。需要完整 Markdown 功能时使用源码模式。大纲和有界思维导图只读取标题，不另存私有文档格式。

## 历史、收藏、模板与附件

每次覆盖前将旧文完整保存为历史；历史入库失败会阻止覆盖。版本可预览，再恢复为当前草稿，仍经哈希冲突检查。收藏和模板标记独立于可重建搜索索引，切换 Vault 不会清除。模板是一篇普通 Markdown，创建副本不会改动模板原文或覆盖同名笔记。

附件通过原生文件框导入：普通附件最多20 MiB，栅格图片最多8 MiB。文件复制至配置的附件目录，可插入 Vault 相对链接、导出新文件或明确确认回收。不会自动清理其他笔记可能引用的附件；不执行附件。配置附件目录及其上级目录不能移动，以免导入记录失去管理路径。

历史当前不会自动删除，长期编辑会增加本地数据库大小；清理 AI 临时缓存不会删除笔记历史。普通附件可通过附件面板管理，Obsidian中仍使用普通附件链接。

## AI整理笔记

「AI整理笔记」先展示将发送的文本；须开启单独的笔记文本权限，并再次授权本次发送。只发送当前笔记文本，不跟随 Wiki/URL，不读取附件、其他笔记、视频或完整音频。输入最多48 KiB，结果最多32 KiB。

Rust安全层保存密钥并调用固定官方 HTTPS 接口；前端拿不到完整密钥。结果先预览，由用户点击应用；当前文档、基线哈希或草稿版本发生变化时拒绝覆盖。取消、撤销授权、切换Vault或源文件变化会阻断后续请求。笔记整理有独立请求计数，Token计入实际用量，不自动收费调用。

## Obsidian联动

首次打开需配置已登记的 Vault ID 或明确名称，可用显式绝对路径兼容模式。系统接受 URI 只代表请求已发送，必须由用户确认目标笔记实际打开才标为联动正常。打开前可保存草稿，或保留编辑并打开磁盘版本。移动笔记时关联更新使用事务及文件补偿。

验收证据见 [交付记录](v0.5.1-delivery.md)；开发契约与原文保存在 `docs/superpowers/`。
