# 映流 v0.3.0 · Media Pro

媒体工具现可完成可视化裁剪、压缩、预设、字幕、批量处理、抽帧、联系表、封面和元数据修改。所有处理通过捆绑 FFmpeg/ffprobe，输出新文件，保留原始文件。

## 可视化裁剪
选择或拖入单个视频，打开“视频裁剪”。预览不支持源格式时点击“生成兼容预览代理”，它只影响预览，导出仍读取原文件。拖动入点/出点或修改毫秒时间输入，相互同步；可预览所选片段，到出点自动停止。
聚焦编辑器：Space 播放/暂停，I/O 入出点，J 倒向寻帧，K 暂停，L 播放，左右移动1秒，Shift+左右逐帧。FPS未知时逐帧禁用。输入框、按钮和下拉框保持原有键盘行为。J 通过连续倒向寻帧模拟，不反向播放音频。
极速无损受关键帧影响；精确裁剪重新编码。缩略图按短于60秒每2秒、60秒至30分钟每5秒、超过30分钟每30秒生成，每组60张。兼容预览代理最多6小时、5分钟生成时间和1GiB文件；超出时提示，不输出不完整代理。离开裁剪页面取消辅助进程并清理会话缓存。

## 压缩和预设
最高质量/平衡/更小体积对应 H.264 CRF18/23/28、H.265 CRF20/26/30。高级选项支持CRF0–51，最高720/1080/1440/2160p、保持帧率或选24/25/30/60；不放大源分辨率。CRF不保证固定文件体积。AV1编码预留，WebM保持既有兼容流无损封装。
手机视频、网页发布、AI素材、归档四个内置预设，可应用或保存当前配置。AI素材另加入20张缩略图任务，独立显示结果。最多50个媒体预设。
设置页“Media Pro”单独保存编码加速与下载完成动作。GPU检测先读编码器声明，再实际编码一帧确认驱动可用。任务硬件编码失败再重试CPU。GPU量化与CPU CRF含义不同，不能保证相同体积/质量。

## 自动处理
默认关闭，可选转换MP4、压缩、封装已有字幕或生成封面。仅处理启用后完成的视频下载，使用独立媒体队列。按来源下载ID和文件去重，重启补偿入队；媒体失败不会触发重新下载，去媒体任务重试。修改动作不会重新处理已有历史。
自动字幕使用已下载或内嵌文本字幕，缺少时明确失败；不执行语音识别。

## 字幕、批处理、图像和标签
SRT/ASS/VTT互转；外挂字幕封装到MKV/MP4/MOV；硬字幕支持字体、8–96字号、底部/居中/顶部和颜色。样式字体支持字母、数字、中文、空格、连字符和下划线。字幕最多8MiB。文本字幕转换不支持位图字幕/OCR。
批量选择多个文件或文件夹，可转换、压缩、提取音频、生成首帧截图。最多500媒体文件/10000目录项目，不跟随链接与junction，逐文件显示错误和重试。
抽帧按间隔/数量/FPS，最多10000张，FPS上限60；结果作为独立目录发布。同名目录自动编号。联系表最多10×10，带时间码、文件名和尺寸。
封面优先提取内嵌图片，没有则取视频首帧；设置封面支持MP4/M4A/MP3/FLAC和JPG/PNG图片（最多50MiB）。音乐标签/封面支持单音轨输入。元数据字段：标题、Artist、作者、日期、描述、Album、Genre、备注，每项4096字以内；未编辑字段保留，空字符串清除。标签显示取决于容器和播放器。

## 安全和限制
结构化参数由Rust验证；不提供任意FFmpeg命令入口。主任务及辅助任务纳入Windows Job，隐藏运行；取消和退出终止进程树。输入仅本地盘符文件；预览asset协议只逐文件授权。字幕/封面复制至任务目录固定文件名，不把用户路径拼进滤镜。
处理成功、结果非空后使用不覆盖的系统移动发布；同名自动编号，任务临时目录位于 `.video-downloader/media-temp/`。下载、Cookie、代理、托盘、历史机制保持原有行为。
预留：AV1转码、完整媒体库、AI处理和素材分析；暂不提供多段拼接、多轨非线性剪辑或完整HandBrake设备参数库。视频预览代理重新编码为兼容格式，不能用其画质评估最终原始画质。真实高DPI Windows、干净Win10/无WebView2安装与个人Cookie未额外验证；原有B站412限制仍可能由源站返回。

官方依据：[FFmpeg filters](https://www.ffmpeg.org/ffmpeg-filters.html)、[FFmpeg CLI](https://www.ffmpeg.org/ffmpeg.html)、[Tauri asset scope](https://v2.tauri.app/security/asset-protocol/)。上游组件版本/许可沿用捆绑清单，新增Tauri传递依赖http-range以支持安全媒体范围请求。
