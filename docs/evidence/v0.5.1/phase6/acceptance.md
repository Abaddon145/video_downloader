# Phase6 — Markdown知识工作台

实现每文档独立串行自动保存、多标签、保存中继续输入、外部冲突暂停、所有打开草稿离开保护、移动前保存/目标检查和成功后重键。托盘退出复用原exit_app关闭链，待保存时返回主窗确认；失败不隐瞒草稿。浏览器beforeunload也检查全部文档。未宣称强制杀进程/断电下未保存输入必定恢复。

schema v8 的收藏/模板、保存前原文历史和导入附件记录独立于可清理索引。历史入库失败不会覆盖Markdown；版本恢复/AI应用继续统一CAS写入。目录移动把关联表放入原事务与补偿；配置附件目录及祖先禁止移动，保证附件仍可管理。附件原生导入、大小/路径/哈希限制、复制/回收和新文件导出，不执行附件。

知识工具支持收藏、普通Markdown模板副本、历史预览/恢复、附件插链/导出/确认回收、基于大纲的有界导图。AI整理需全局笔记授权和每次确认，仅发送当前文本，结果预览后显式应用；源/输入hash与编辑版本检查阻止迟到结果替换新稿。单独记录实际noteRequests与tokens。无路径/SQL/工具执行。

Tiptap 3.32.0按官方React安装文档核验并固定在lockfile。富文本只开放可证明往返的段落/标题/粗体/斜体子集；未编辑原文逐字保留。YAML、Wiki、附件、任务、代码、特殊语法、BOM/CRLF及非规范排版回退CodeMirror；仍可源码编辑和预览。ProseMirror交易过滤拒绝不能安全写回的变更并提示，避免先显示后丢稿。不引入DCC私有JSON主存储。
