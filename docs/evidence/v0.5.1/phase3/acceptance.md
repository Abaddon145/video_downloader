# Phase 3 — 统一右键与业务动作

通用菜单支持右键、Shift+F10、方向键/Home/End/Enter/Escape/Tab、子菜单、分组、禁用、滚动、边界定位、焦点返回、失败反馈与原生视频遮挡标记。输入区域保留系统编辑菜单。

学习系列三视图、课程、下载队列/历史、媒体任务和知识树已接入同一组件。下载/媒体冻结真实选中集；危险操作保留确认。下载已完成媒体可交给批量处理面板；媒体批量整理使用已有 BatchPanel，安全移除仅移除终态记录，不删除输入/输出。

课程移动只更新系列归属与顺序，保留 ID、文件路径、进度和笔记。知识菜单的重命名/移动/复制/删除使用右键目标而非当前打开笔记，保留未保存保护和 expectedHash。笔记本可新建、移动、重命名、名称排序、展开/折叠和确认删除空目录；Windows 原子检查拒绝非空目录。Markdown 导出由 Rust 读取 Vault 内文件，在原生保存框选择新文件，不覆盖既有文件；Obsidian 菜单复用 Phase1 向导。
