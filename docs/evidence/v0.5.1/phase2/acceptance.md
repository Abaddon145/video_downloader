# Phase 2 — 学习库与播放器布局

学习库卡片、列表、表格共用系列操作；数据库白名单排序在分页前执行，聚合时长、进度、可用文件和 AI 状态。AI 状态只统计当前源文件的非本地转录分析。

播放器标准、上下、剧院、专注布局复用同一原生会话和笔记面板；分隔线支持鼠标和键盘。上下/剧院布局的短内容也实际改变高度。分类、列宽、显示、密度、面板设置保存在独立 workspace.json，浏览器仅保存布局待写入日志。读取失败且无有效日志时暂停编辑并重新读取，避免默认值覆盖磁盘。保存失败有可重试提示。
