# Phase 6 — 字幕、AI、知识笔记与撤销

正式分支验证：前端 101 通过；Rust 254 通过、8 个原有显式忽略；TypeScript/生产构建通过。见 `node.txt`、`rust-full.txt`、`build.txt`。

模拟 Edge 工作流：

- `ui/checks.json`：8 组通过。整课字幕搜索后分页、选区预填而不自动调用 AI、关闭字幕上传时禁止发送、笔记新建/追加先预览确认、精确原文/时间引用、外部冲突、撤销、任务失败状态。
- `recovery-ui/checks.json`：9 组通过。收藏迟到响应、重命名/移动撤销、外部 hash 变化、回收恢复不覆盖新文件、回收内容篡改、失败重试、共享时间点插入、子文件夹展开/折叠。
- 这些是模拟桥接验收，不代表付费 DeepSeek、物理键盘、Obsidian 客户端或原生视频画面已实机验收。

安全实现：

- 学习库撤销仅返回后端签发的会话凭据，最多 30 条；成功后消费，冲突后保留。前端不能提供任意原值或排序值。
- 笔记移动以原文 hash 校验；回收通过会话 receipt 只允许恢复原位，拒绝覆盖、篡改或跨 Vault。
- Markdown 追加保留 BOM、CRLF、原有尾部空白；保存和撤销都检查磁盘 hash。
- 选中字幕传给 AI 仍需要设置允许字幕上传，并由用户显式发送；AI 没有独立一级导航。

已知边界：业务撤销为会话内记录，重启不恢复；回收文件仍留在隐藏回收目录。笔记本目录移动复用原有安全移动，但不提供无法验证整个目录状态的撤销。未添加永久删除或清空回收目录功能。

测试中修正了过时的模拟接口（新增任务快照应返回数组）以及折叠菜单操作步骤；未弱化断言或删除既有测试。`failure.png` 为保留的排查中间图，最终判断以检查 JSON 为准。
