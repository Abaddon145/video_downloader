# Phase10 桌面回归补充诊断

- 退出课程后的重复保存：父组件和原生Surface在卸载时各自保存，后者已关闭，前者误报“播放会话已关闭”。浏览器断言先失败后通过，活动会话的真实磁盘写入错误继续展示。
- 进度测试最初使用4秒，既有Repository规则会将不足5秒的非结束进度存为0，以避免误触留下记录。测试改用6秒，不修改原规则。
- 字幕缓存读取偶发路径不存在：真实桌面失败报告与截图见 `learning-knowledge-routing-cache-failure.*`。缓存TTL将毫秒now与秒mtime/天数比较，后台会把新字幕缓存误判为过期。读取与清理的共享锁也必须涵盖AI字幕缓存。
- 共享原子保存原先使用固定.new文件。新增8线程并发检查，原实现出现7个“系统找不到指定的文件”错误；仅改唯一临时文件后仍出现Windows并发替换拒绝访问。唯一临时文件加短串行发布后native测试7/7通过。不会静默吞掉真正的磁盘写入错误。

最终通过结果以本目录最新desktop JSON和完整Rust日志为准；以上失败均为真实执行，不计为通过结果。
