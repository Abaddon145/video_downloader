# Windows 视频下载器 — 实施与验收

已确认的产品方案：Tauri 2 + React + TypeScript，Windows 10/11 x64，中文深色界面，官方 yt-dlp 内核。

## 实施任务

1. 内核边界：链接/代理校验、官方结构化输出、文件保护、进程树、DPAPI 与原子存储。
2. 下载服务：预览、单条/批量/播放列表、格式选择、并发队列、暂停/重试、历史、更新。
3. 界面：下载工作台、解析预览、历史、设置、托盘；键盘/缩放/减少动画验证。
4. 交付：固定并校验下载组件，构建 NSIS 安装包，真实平台下载与发布包冒烟验证。

## 约定

- 默认并发 2，最高兼容 MP4，音频 MP3，启用字幕后 SRT；默认系统下载目录内“视频下载”。
- 下载关闭窗口后进入托盘；主动退出或异常中断的任务下次恢复为暂停，需手动继续。
- 预览确认后入队，播放列表可勾选；列表每页 50 条。
- 浏览器 Cookie 与文件导入、HTTP/SOCKS5 手动代理；敏感数据 DPAPI 本地保护。
- 仅处理 http/https 输入，通过参数数组启动官方 exe，禁用外部配置，不覆盖已有文件。
- 合并/转换结束后才算完成；下载阶段暂停通过停止进程再续传实现，处理阶段支持取消。
- 内核默认 stable，空闲时手动更新，严格校验 SHA256 和启动检查，保留旧版回滚。

## 验证命令

```powershell
npm test
npm run build
cargo test --manifest-path src-tauri/Cargo.toml
npm run tauri -- build --bundles nsis
```

重点验证 B站/YouTube 视频、音频、播放列表和字幕；记录网络或登录造成的实际限制，不把模拟结果当作真实下载。
