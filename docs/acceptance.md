## 0.1.1：B站 412 错误诊断（2026-10-09）

用户报告 `BV17eHY6yEwc` 无法解析，独立执行官方内核也复现 HTTP 412；Chrome 兼容请求同样失败。公开匿名会话接口检查遇到 TLS 握手失败。未读取用户个人登录 Cookie，尚不能确认登录后的浏览器是否可以播放。

本次修订将 B站 412 转为中文原因和操作说明，增加打开原网页、进入登录与网络设置、重新解析三个入口；原始日志折叠在技术详情中。设置跳转保留输入链接。Python 3.10 提示来自捆绑的独立内核，不应要求用户安装 Python 来处理这个错误。

上游同类问题：[yt-dlp #14830](https://github.com/yt-dlp/yt-dlp/issues/14830)。本修订改善错误处理，没有声称解除源站的请求限制。

检查：Node 3/3，TypeScript / Vite 生产构建通过。已安装桌面版实测通过：实际 412 显示中文引导、原网页与重试入口、技术详情默认折叠、跳转设置后原输入链接保留。验收使用独立 WebView2 目录，避免与日常窗口共享浏览器进程。

后续诊断：正式软件仍为 Cookie 关闭、代理关闭。官方内核读取默认 Edge Cookie 时 DPAPI 解密失败；全新独立浏览器直连同视频返回 412；公开匿名会话接口在 curl 和独立浏览器中分别发生 TLS 握手失败、连接被关闭。未导出个人 Cookie，临时匿名会话文件已清理。尚需用户确认日常浏览器中的实际可播放状态。
