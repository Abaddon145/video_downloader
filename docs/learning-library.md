# 映流 v0.4.0 学习库

Windows 10/11 x64 本地学习库。教程视频保留在原位置，课时目录、观看记录与笔记保存在本机。

## 添加教程

- 在“学习库”创建分类和系列，可重命名、编辑描述、选择封面、收藏；拖动手柄或上下箭头调整顺序。
- 选择视频、批量选择或导入文件夹，也可拖入本地视频/文件夹。先预览，确认后才写入目录；数字序号按 1、2、10 排列。同一规范路径重复导入会跳过。
- 在下载预览中勾选“下载后加入学习库”，设置系列与分类。完整播放列表建立课时目录，已勾选的课时进入原下载队列；未选课时可以稍后下载。
- 播放列表按来源视频 ID 优先、URL 兜底去重，名称变化不会重复加入。系列详情的“检查系列更新”沿用原解析器，只列出新增课时。

## 播放和继续学习

点击课时播放。提供进度条、上一课/下一课、音量、静音、全屏、0.5–2× 七档倍速。格式无法直接播放时可生成兼容预览，视频原文件保留。

进度每 5 秒写入 SQLite；暂停、切课、离开学习库、窗口隐藏和退出也会保存。打开不足 5 秒时不会覆盖旧的有效位置。默认观看 90% 标记完成，也可手动标记完成/未完成。未完成课程出现在“继续学习”，按最近观看排序。

播放结束后等待 5 秒自动播放下一课，可取消。默认倍速、完成阈值、恢复位置、自动续播和自动字幕可以在“学习设置”调整。下一课未下载时保留等待状态。

快捷键：Space 播放/暂停，左右方向键前后 5 秒，Shift + 左右方向键 10 秒，M 静音，F 全屏，N/P 上下课。在输入框、选择框或笔记中输入文字时，这些快捷键不触发。

同名 SRT/ASS/VTT 与可转换的内嵌文本字幕会转换为本地 WebVTT 播放，也可手动选择字幕或关闭。位图字幕不支持文本转换。目录内自动匹配最多 4 个字幕文件，每个不超过 8 MiB；大文件夹扫描有数量上限。

## 时间点笔记

点击“添加笔记”会暂停视频并记录当前位置。可以编辑时间、内容、删除笔记；点击如 `12:30` 的时间按钮回到该位置。学习库搜索覆盖分类、系列、课程标题和笔记内容。

## 文件和数据保护

移除分类时，系列转到“未分类”。移除课时或系列默认只删除目录记录。选择删除本地文件后还需第二次确认；其他课时引用同一文件时会阻止删除。目录记录删除会连带移除该课时的观看记录与笔记。

文件已移动或不可访问时，选择“重新定位视频”；保留原来的课时身份、笔记与观看记录。打开文件位置、封面、播放和字幕只授权选定的普通本地文件，拒绝设备、网络路径和链接文件。

数据默认位于 `%LOCALAPPDATA%\com.local.video-downloader`：`learning.db`、SQLite WAL/SHM（运行时）和 `learning-covers`。备份时先从托盘保存并退出，再复制数据文件夹；视频仍需单独保留。学习库初始化失败会显示独立错误，旧下载与媒体任务仍可使用；修复文件权限或数据库后可重试。软件不会自动删除损坏数据库。

旧 `state.json`、`media-state.json` 与下载生命周期保持兼容。学习库使用独立、版本化的 SQLite 迁移：v1 基础表，v2 来源/路径键与设置，v3 有序进度和统计触发器，v4 下载请求索引。未知未来版本会拒绝打开并保留文件。

## 范围与验证

长列表按每页 50 条展示，测试覆盖 100 分类 / 1,000 系列 / 10,000 课时。首次导入每次最多 500 个本地文件，单播放列表最多 1,000 课。兼容预览沿用已有媒体服务的时长、时间和体积限制。

本版包含 P0 以及系列更新和收藏。AI 总结、OCR、字幕转录/全文检索、云同步、在线服务与多轨剪辑未加入本版。网络平台支持仍继承 yt-dlp，实际测试范围见[交付与验收](learning-library-delivery.md)。

实现依据：[rusqlite](https://docs.rs/rusqlite/0.32.1/rusqlite/)、[SQLite user_version](https://www.sqlite.org/pragma.html#pragma_user_version)、[HTML 文本字幕轨道](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/track)。
