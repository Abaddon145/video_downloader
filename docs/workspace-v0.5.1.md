# 映流 v0.5.1：外观与工作区

在「设置 → 外观与工作区」调整深色、浅色或跟随系统主题、强调色、字号、三档信息密度、侧栏宽度与动画。更改即时生效并保存在本机；文字强调色会保留可读对比度。

学习库提供卡片、列表和表格三种视图，可设置分类栏、封面比例、列顺序/可见列/列宽和排序。播放器提供标准、上下、剧场、专注四种布局，继续使用同一个 mpv 播放会话。分隔线支持鼠标拖动及键盘方向键，Shift 加快调整。

五个内置布局为默认、视频学习、专注播放、批量管理和知识整理。可以应用内置预设，或给当前布局命名、新建自定义预设，之后更新、重命名、删除。预设只保存布局，外观独立；恢复默认工作区保留自定义预设。

布局配置导入/导出使用原生 JSON 文件选择框，只包含外观、布局和预设。文件不超过 128 KiB，未知字段、凭据、未来版本与无效数值会被拒绝；导出使用新文件名，不覆盖已有文件。配置读取失败保留原文件；有效的待保存布局可在下次启动恢复。

下载、历史、学习系列/课程、媒体任务和知识文件树共用右键菜单。可用 Shift+F10 打开，方向键选择，Enter 执行，Escape 返回；菜单动作使用真实右键目标和选中集。移除下载或媒体记录会保留媒体文件，危险操作仍需确认。

AI仍从学习库具体课程进入。分析前选择十类用途模板及快速/标准/深度；官方模板只读，可复制为自定义版本。每次分析冻结用途快照，修改或删除模板不会重写旧结果。切换用途可复用经过校验的本地语音和画面；重新总结建立新记录，完整分析重新处理素材。

自动验收与限制见 [v0.5.1交付记录](v0.5.1-delivery.md)。
