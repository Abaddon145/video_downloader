# 映流 v0.4.1：多格式播放与课程图片

点击学习库里的课程即可开始准备并自动播放。原视频保留在原路径，学习进度与笔记跟随课程，不会随缓存清理消失。

## 播放与字幕

支持导入 MP4、M4V、MOV、MKV、AVI、WMV、ASF、WebM、FLV、MPG、MPEG、TS、M2TS、MTS、3GP、3G2、OGV；最终由 ffprobe 检查真实视频轨道。直接选择的改名视频也可导入。

播放器先检查浏览器能力与实际编码。可播放的文件直接打开；例如 MKV 的 H.264/AAC 会优先无损封装。WMV 等需要时自动转成 H.264/AAC；界面显示进度、剩余时间并可取消。转换通过原有媒体队列与硬件加速设置执行，GPU 无法使用或编码失败时回退 CPU。

同名 SRT、ASS、SSA、VTT 及内嵌文本字幕会转换为缓存 VTT，不需要为了字幕重新压制整个视频。支持七档倍速、拖动定位、上次位置恢复、完成标记、笔记与下一课。

学习设置里可选择“自动选择”“优先原始视频”或“始终生成兼容视频”。高级操作“重新生成兼容视频”会保留原文件；“播放技术详情”显示实际容器和编码。错误可重试、重新定位或打开文件位置。

## 课程缩略图

课程行显示图片、时长、观看进度及完成标记。图片顺序为手动设置、已缓存的源站图片、视频抽帧、系列封面、默认图标。缺失视频仍保留已生成图片。

图片在后台逐张处理，不等待全部图片才完成导入。统一为320×180 JPEG，保留比例并补边；长视频取12%时间点，5至30秒取25%，不足5秒取50%，避开首帧。TS/M2TS 等稀疏关键帧视频必要时进行一次精确抽帧重试。

点击课程右侧“…”可设置 JPEG/PNG/WebP 缩略图、重新生成、重命名、重新定位、排序或移除。手动图片会复制到缓存；重新生成需要确认，选择的原图片会保留。菜单支持键盘与 Escape。

## 缓存与备份

缓存位于应用数据目录的 `learning-cache/playback`、`thumbnails`、`subtitles`。可在“学习设置”查看实际用量；播放缓存默认50GiB，超过30天未使用可自动清理，0天关闭按日期清理。

正在准备或播放的视频会保留；缩略图仅清理数据库不再引用的图片。清理不会删除原视频、课程、进度或笔记。源文件尺寸、修改时间、编码或目标配置变化后，播放缓存重新生成；缩略图单独更新。不要手工修改缓存目录或放入个人文件。

退出应用后备份整个应用数据目录可以保存数据库与缓存。学习库损坏会显示错误并支持修复后重试，下载和媒体工具仍独立可用。详细验收见[交付报告](learning-playback-v0.4.1-delivery.md)。

实现参考：[MediaCapabilities](https://developer.mozilla.org/en-US/docs/Web/API/MediaCapabilities/decodingInfo)、[FFmpeg 文档](https://ffmpeg.org/ffmpeg.html)、[Tauri Windows 安装包](https://v2.tauri.app/distribute/windows-installer/)。
