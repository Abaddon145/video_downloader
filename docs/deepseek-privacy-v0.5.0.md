# DeepSeek与本地数据：隐私说明

本文说明映流 v0.5.0 开发版本的 AI 数据流。真实 DeepSeek 小规模短片验证已完成；具体请求范围和证据见[交付记录](ai-video-analysis-delivery.md)。

## 哪些内容留在电脑上

原始视频、完整 WAV 音频和本地 Whisper 语音识别都在电脑上处理。映流优先使用课程已有的有效文本字幕；没有可用字幕且媒体有音轨时，才使用本地 Whisper。Whisper 模型由用户首次使用时下载或导入，并在本机运行。

## 哪些内容可能发送给 DeepSeek

发送前可控制两类内容：字幕文字，以及从视频中选取并缩放的 JPEG 关键帧。AI分析至少需要允许其中一类内容；关闭两项仍可做本地语音转录，但不会把课程内容提交给 DeepSeek 来生成理解结果。请求会使用当前任务所需的文字或画面，不上传原视频文件，也不上传完整 WAV。

普通总结和问答会把模型请求发送至 DeepSeek 官方 HTTPS 服务。问答先在本机从课程材料中查找相关片段，再使用需要的内容组织回答。测试连接只读取模型列表，不发送课程内容。AI设置通过系统网络连接；下载代理仍由原有下载设置控制。

## API密钥

API密钥通过 Windows 原生安全输入窗口设置或更换，不需要把密钥粘贴到课程、聊天或笔记中。映流后端在本机使用 Windows DPAPI 加密保存密钥；界面只显示“已设置”状态，不读取或回显明文。可在 AI 设置中删除密钥。API 调用和密钥处理由 Rust 后端执行，React 界面不持有密钥。

## 笔记和自动任务

AI分析总结、转录缓存和笔记保存在本机应用数据或用户选择的知识库中。知识库笔记是普通 Markdown 文件，可自行查看、备份或删除。生成笔记使用已有分析结果，不会单独为写文件产生模型费用；重新分析、总结或问答等模型请求可能产生费用。

下载完成自动分析默认关闭。启用后，只有之后完成的下载会自动进入分析；关闭后映流不会在启动时追跑历史下载。自动生成知识笔记默认开启，但需先选择知识库。费用估算仅供参考；AI设置显示输入、输出和缓存的原始 Token 数，实际费用以 DeepSeek 账户账单为准。

## 当前验证范围

模拟 HTTP 用于异常、隐私和恢复回归。真实官方 API 已完成一段公开演讲短片的本地转录、JPEG 分析、总结、章节和问答验证；验收凭据随后删除。该结果不代表正式 Release 或所有 Windows 配置均已验证。有关本地知识库文件的编辑、备份和删除行为，见[知识库说明](knowledge-vault-v0.5.0.md)。
