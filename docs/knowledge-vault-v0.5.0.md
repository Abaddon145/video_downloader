# 映流知识库 v0.5.0

知识库以普通 Markdown 文件保存笔记，映流和其他 Markdown 编辑器都可读取。搜索、标签和双向链接等索引保存在应用的 `learning.db` 中，可从笔记文件重新扫描建立。知识库随 v0.5.0 候选安装包交付；真实 Obsidian 联用及所有 Windows 环境尚未完成验证。

## 创建和选择知识库

在知识库页面选择本机文件夹作为 Vault。默认建议位置是“文档/映流知识库”；可使用已有本地文件夹，也可让映流新建文件夹。知识笔记默认放在 `映流` 子目录，图片附件默认放在 `Attachments` 子目录。可切换知识库文件夹；生成附件遵循保存的附件目录配置，当前界面不提供子目录名编辑。笔记与图片存放在你选的文件夹内；应用设置和索引存放在应用数据目录。

知识库可在 Obsidian 中直接打开，无需安装 Obsidian 才能使用映流。映流不会创建或改写 `.obsidian` 配置。可以从映流请求在 Obsidian 中打开笔记；若系统没有可用的 Obsidian 启动程序，Markdown 文件仍可正常使用。

## 浏览、搜索与编辑

知识库页面提供文件树、全文搜索、标签、反向链接、目录大纲、编辑、预览和分屏。支持 `[[笔记]]`、`[[路径/笔记#标题|显示名]]` Wiki 链接；链接有多个匹配时会列出候选。课程转录也可在知识库中搜索，课程引用可跳回映流播放器。

编辑器保存时会检查磁盘文件是否在打开后被外部修改。发现变化时会展示冲突和当前文件内容，由你决定重新加载或以最新版本为基础继续保存，避免静默覆盖。离开未保存笔记时会提示。索引由磁盘 Markdown 重建；外部编辑文件后，重新扫描可刷新搜索、标签和反向链接。

笔记以 UTF-8 Markdown 保存，单文件上限 5 MiB；图片附件支持 PNG、JPG/JPEG、GIF、WebP、BMP 和 AVIF，单个附件读取上限 8 MiB。预览不会执行笔记中的原始 HTML，也不会自动载入远程图片。知识库操作限制在所选根目录内，并拒绝符号链接、junction 等重解析路径；`.obsidian`、`.git`、`node_modules` 等受保护目录不会作为普通笔记浏览或编辑。

## AI课程笔记

在课程 AI 面板可把分析结果生成或更新为知识库中的 Markdown 笔记。开启设置中的“分析完成自动生成知识笔记”后，新分析会尝试写入当时选定的知识库；此选项默认开启，但未选择知识库时不会有可写入的位置，分析结果仍保留，可稍后手动生成。生成笔记的内容来自已有分析结果，不会因此额外收取重新分析整部视频的费用；若之后主动重新分析，仍可能产生模型调用费用。

一次生成会建立三份互相链接的 Markdown 笔记：`视频总结`（概要和章节）、`完整转录`（带时间点的字幕）及`关键知识`（知识点、教程步骤、术语和待办）。正文可再按个人习惯编辑。截图笔记从课程播放位置创建，附带 JPG 截图及时间点链接。AI 生成的 Markdown 是笔记正文的唯一来源；应用数据库只保存课程关联与搜索索引。生成的 YAML 元数据包含来源标记、课程时长、模型、分析模式和 `analyzed_at`。其中 `analyzed_at` 使用 Unix 毫秒时间戳；课程源文件路径默认不会写入导出的笔记。

自动生成或更新可能失败，例如 Vault 未选、生成期间切换知识库或磁盘不可用。此时课程分析仍保留，页面会提示警告，可检查知识库后手动重试。分析设置中的删除分析只删除分析记录并保留知识库笔记；若要一并删除当前版本的生成笔记，需在确认步骤中选择联合删除。联合删除只处理仍与当前分析版本一致且未被编辑的文件；已编辑文件和旧版本文件会保留。截图笔记和普通个人笔记不会随分析记录自动删除。

## 文件保护和限制

新建、重命名和移动不会覆盖已有目标。删除的笔记会移入知识库内的 `.yingliu-trash` 回收目录。外部编辑器不受映流内部保存锁保护；多个程序同时写同一文件时，请先停止并发编辑，再重新扫描。索引扫描可能跳过无法读取或超过限制的内容，并标记结果不完整；此时不会清除未能确认的旧索引。

知识库后端及界面的阶段记录可见仓库中的 `evidence/ai-v0.5.0/phase8/acceptance.md` 和 `evidence/ai-v0.5.0/phase9/acceptance.md`。这些记录是特定本机检查结果，不代表真实 Obsidian 联用或全部 Windows DPI/环境均已验证。安装包与本机验证状态见[交付记录](ai-video-analysis-delivery.md)。
